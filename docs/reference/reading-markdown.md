# 书摘 Markdown

页面 `/tools/reading` 从 `jacory-space-frontend/src/content/reading/*.md` 加载书籍。每本书一个文件，文件名为稳定标识，按文件名排序；书内按摘抄书写顺序展示。

```md
---
title: "书名"
author: "作者姓名"
edition: "译者 / 出版社 / 出版年份"
---

## 001

> 摘抄原文。
>
> 原文第二段。

摘录时间：2026-09-24 15

随记：自己的理解，可省略。
```

书名、书内唯一的数字编号、引用原文和有效摘录时间（YYYY-MM-DD HH，小时为 00–23，按北京时间 UTC+08:00 记录）必填。作者、版本、随记可省略。原文每行以 `>` 开头；页面按原样文本展示，不执行 HTML，也不处理引用内部的 Markdown 强调语法。随记放在该条摘抄的最后。

不记录或展示出处、章节和页码。原文保留录入语言，界面文案支持三语言。

`example.md` 是明确标记 `sample: true` 的展示样例，不是真实书摘；仅开发模式显示，正式构建不展示，也不计入目录、搜索结果与统计。复制为真实书籍时移除 `sample: true`，替换全部示例内容。无书籍时页面展示空状态。

## 时间排列

页面支持「按书籍 / 按时间」切换，切换时保留搜索条件。按书籍保持文件和摘抄的原始顺序；按时间跨书籍汇总，按日期分组，日期与同日小时均倒序，每条显示所属书名。页面只展示 YYYY-MM-DD，不展示小时。

旧的 `摘录日期：YYYY-MM-DD` 仍然有效；未知小时不补造。同一天里，只有日期的旧记录排在有小时的记录后；相同时间按文件名及摘抄编号稳定排列。新增摘抄使用 `摘录时间：YYYY-MM-DD HH`。
