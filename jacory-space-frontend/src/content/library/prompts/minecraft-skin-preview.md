【两种输入模式】

模式 A：纯文字设计

- 未指定的发型、肤色、配件、背面细节可自行补全；
- 每条新需求默认是新的独立角色。

模式 B：参考图转换
当我发送一张或多张角色参考图，并说明“参考图生成”“按这张图生成”或类似意思时：

【每次图片输出的固定规范】

1. 输出一张横向双联图：
   - 左边：同一角色的正面三分之四全身视角，旋转角度约 40°；头部和躯干的窄侧面必须出现在画面左侧，主要正面必须出现在画面右侧；

2. 两侧必须是完全同一个角色：
   - 发型、发色、脸部、服装、配色、鞋子和配件连续一致；
   - 背面必须是正面设计在背部和侧面的合理延续；
   - 站姿、比例、镜头高度、缩放大小一致；
   - 手、脚、头部和身体全部可见，不裁切。

3. 角色必须严格使用标准 Minecraft Java 玩家模型：
   - 默认 Classic 宽手臂模型；只有我明确说“Slim”时，才使用 Slim 细手臂模型；
   - 保持原版固定几何结构：一个立方体头部、一个长方体躯干、两条长方体手臂和两条长方体腿；
   - 角色设计主要通过标准 64×64 Minecraft Skin 的像素纹理表现，而不是通过自定义体素建模表现；
   - 头部、躯干、双臂和双腿必须保持原版 Minecraft 玩家模型的完整、平整方块表面；
   - 除原生第二层产生的轻微、统一外扩外，角色整体轮廓不得超出标准 Minecraft 玩家模型各身体部件的长方体边界；
   - 不是现实人物、普通立绘、UV 展开图或非 Minecraft 比例角色。

4. 外侧层只允许使用 Minecraft Java 皮肤系统原生的第二层：
   - 只允许帽子层、外套层、袖子层和裤子层；

5. 使用标准 Minecraft 皮肤的低分辨率像素绘制方式：

6. 长发、辫子、裙摆和垂落布料必须按照 Minecraft 皮肤规则简化：

   - 裙装的层次、开衩、布料拼接和下摆变化，应优先转化为腿部纹理图案、明暗分区和少量第二层覆盖，而不是新增几何轮廓；

7. 使用接近 Minecraft 皮肤编辑器预览窗口的简单均匀光照：
